# PaperDoll

[![Modrinth Downloads](https://img.shields.io/modrinth/dt/edwFXb9k?logo=modrinth&label=Modrinth)](https://modrinth.com/mod/paperdoll)
[![CurseForge Downloads](https://img.shields.io/curseforge/dt/537079?logo=curseforge&label=CurseForge)](https://www.curseforge.com/minecraft/mc-mods/paperdoll)

## Configuration

You can access the config screen from the Modlist (Fabric requires [ModMenu](https://github.com/TerraformersMC/ModMenu) for this; for Forge, you may use [Game Menu Mod Option](https://github.com/MORIMORI0317/GameMenuModOption)). While in-game, you will also get a live preview of the applied changes.
